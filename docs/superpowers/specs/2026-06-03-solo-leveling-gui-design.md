# Solo Leveling 风格 SSH 工具浮动面板设计

## 概述

将 SSH 工具从命令行界面改造为《我独自升级》(Solo Leveling) 动漫风格的精简浮动面板 GUI。打包为 exe 后不显示 cmd 窗口，以悬浮半透明面板展示操作进度、命令输出和最终结果。

## 设计目标

- **无控制台窗口**：exe 运行时无 cmd 黑框
- **游戏化视觉**：暗色主题 + 青蓝发光 + 系统通知风格
- **精简信息**：只展示关键信息（连接状态、输出、进度、结果）
- **低侵入**：浮动面板可随意拖动，不干扰其他操作

## 界面布局

```
┌──────────────────────────────────┐
│ ⚜ SYSTEM  ⚜                     │  ← 亚金色标题栏（可拖动）
├──────────────────────────────────┤
│  ◆ CONNECTING                    │  ← 连接状态
│    ● 192.168.1.1:22              │    青色点 + 地址
│                                  │
│  ──── STEP 02/05 ────           │  ← 步骤分隔线
│                                  │
│  $ cd /home/project              │  ← 命令（暗青色）
│  $ ls -la                        │
│  total 24                         │  ← 输出（灰色）
│                                  │
│  ████████████░░░░  60%           │  ← 进度条（发光蓝）
│                                  │
│  ✓ ALL COMPLETED                 │  ← 最终状态（成功/失败）
│                                  │
└──────────────────────────────────┘
```

## 组件说明

### 1. 自定义标题栏
- 左侧显示 "⚜ SYSTEM ⚜"（金色）
- 右侧显示关闭按钮 "✕"
- 整个顶栏可拖动窗口

### 2. 连接状态区
- 动态显示连接中的服务器地址
- 青色圆点表示活跃连接
- 连接失败时转为红色并显示错误信息

### 3. 操作日志区
- 只读文本框，支持彩色标签
- 实时追加命令和输出
- 自动滚动到底部

### 4. 进度条
- Canvas 绘制发光进度条
- 青蓝渐变填充
- 同步更新百分比文字

### 5. 状态提示区
- 操作中 / 成功 / 失败 三种状态
- 成功：绿色 ✓ + 消息
- 失败：红色 ✗ + 错误信息
- 操作中：青色 ⟳ + 消息

## 动画效果

- **进度条填充**：平滑过渡（50ms 步进）
- **状态切换**：文本颜色渐变切换
- **面板出现**：淡入（alpha 0→0.92）
- **日志追加**：新行淡入效果

## 技术实现

### 依赖
- Python 标准库：`tkinter`、`threading`、`queue`
- 无第三方 GUI 依赖（Tkinter 内置）

### 架构

```
┌─────────────────────────┐
│   SoloLevelingGUI       │  ← Tkinter 主窗口
│   (浮动面板)             │
├─────────────────────────┤
│   GuiOutputHandler      │  ← 将控制台输出重定向到 GUI
│   (队列 + 定时器刷新)     │
├─────────────────────────┤
│   main()                │  ← 现有逻辑，注入 GUI 输出
│   (ssh 操作流水线)        │
└─────────────────────────┘
```

### 线程模型
- **主线程**：Tkinter 事件循环（UI 更新）
- **工作线程**：SSH 连接 + 命令执行
- **线程通信**：`queue.Queue` 传递消息
- UI 更新通过 `after()` 定时器轮询队列

### 输出适配

现有的 `ConsoleOutput` 将被替换为 `GuiOutput`，它实现相同的接口方法（`header`、`connection`、`info`、`line`、`remote`、`success`、`error`），但将文本渲染到 GUI 面板上并用队列安全地传递到 UI 线程。

## 打包配置

修改 `build_exe.bat`（或创建新脚本），PyInstaller 参数变化：

```bash
pyinstaller --clean --onefile --noconsole --paths src --name ssh-tool src/ssh_tool/main.py
```

关键变化：`--noconsole` 替代默认的控制台模式，使 exe 运行时无 cmd 窗口。

## 条件运行逻辑

- 当通过 `python` 直接运行时 → 使用控制台模式（保留原有行为）
- 当通过 `pythonw` 或打包 exe 运行时 → 启动 GUI 面板
- 检测方式：`sys.executable.endswith('pythonw.exe')` 或 `hasattr(sys, 'frozen')`

## 文件变更清单

| 文件 | 操作 | 说明 |
|------|------|------|
| `src/ssh_tool/main.py` | 修改 | 注入 GUI 输出，条件判断运行模式 |
| `src/ssh_tool/console_output.py` | 保留 | 保留原控制台模式，新增 `gui_output.py` |
| `src/ssh_tool/sl_gui.py` | 新建 | Solo Leveling 浮动面板 GUI 实现 |
| `build_exe.bat` | 修改 | 添加 `--noconsole` 参数 |
| `config/operations.txt` | 保留 | 无需修改 |
| `pyproject.toml` | 修改 | 添加 `pythonw` 入口点（可选） |
